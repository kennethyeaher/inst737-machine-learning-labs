## Overview

A collection of tutorial-based machine learning exercises. The current scripts explore train/test separation through linear regression and compare Gini and entropy criteria in decision-tree classification.

## At a glance

| Area | What to look for |
| --- | --- |
| **Train/test split** | A California Housing exercise prints training and test scores with sample predictions. |
| **Decision trees** | A Balance Scale exercise compares Gini and entropy and draws the resulting trees. |
| **Evaluation** | Accuracy, confusion matrices, and classification reports accompany the classification exercise. |

## Start here

Use a Python environment with pandas, NumPy, scikit-learn, and Matplotlib installed. Run a script directly:

```sh
python split-tutorial-KennethYeaher.py
python decision-tree/decision-tree-tutorial-KennethYeaher.py
```

## Scope

These are learning exercises, not packaged models. Dataset retrieval needs network access, and the tree script opens plots in a graphical environment.
